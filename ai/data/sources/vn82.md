[Bản công bố](https://huggingface.co/datasets/star092304/Traffic-sign-detection-VietNam/tree/bd948a572cefbea92a1c523a2784c1ea9cf1dbe1)

Bên phát hành chia tập ngẫu nhiên theo từng khung hình. Có 3.393 cặp ảnh liền số nằm khác tập. Trong 300 cặp lấy mẫu, khoảng 2/3 gần như trùng nhau theo hash trung bình 16×16.
```python
import yaml
from ultralytics import YOLO

dataset = Path("/content/vn82-colab")
config = yaml.safe_load((dataset / "data.yaml").read_text())
config["path"] = str(dataset)
config_path = dataset / "colab.yaml"
config_path.write_text(yaml.safe_dump(config, sort_keys=False))
YOLO("yolov8s.pt").train(data=str(config_path), epochs=50, imgsz=640, batch=16, device=0)
```

YOLOv5 dùng `data.yaml` với thư mục gốc được gắn theo cách tương tự. DETR dùng `coco/{train,val,test}.json` và tìm ảnh tương đối từ `vn82-colab/`. [Định dạng tập detection YOLO](https://docs.ultralytics.com/datasets/detect/)

## Dựng lại

Chạy từ thư mục `ai/`. Bỏ qua hai lệnh tải nếu tệp gốc đã có trong `data/raw/`.

```sh
uv pip install -e '.[data]'
mkdir -p data/raw
revision=bd948a572cefbea92a1c523a2784c1ea9cf1dbe1
base="https://huggingface.co/datasets/star092304/Traffic-sign-detection-VietNam/resolve/$revision"
curl -fL "$base/traffic-sign-detection-vietnam.zip" -o data/raw/vietnam-traffic-signs-82.zip
curl -fL "$base/classid.csv" -o data/raw/vietnam-traffic-signs-82-classes.csv
uv run --no-sync python scripts/prepare_vn82.py \
  --archive data/raw/vietnam-traffic-signs-82.zip \
  --classes data/raw/vietnam-traffic-signs-82-classes.csv \
  --output data/processed/vn82-colab
(cd data/processed && zip -q -r vn82-colab.zip vn82-colab)
```
